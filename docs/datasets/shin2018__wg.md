# Shin2018__WG

- Subjects: 26
- Epochs: 1560
- Classes: 2 (BL, WG)
- Task: BL vs WG (Working Memory)
- Task type: Working Memory (n-back/WM)
- LOSO Acc: 63.1%
- Within Acc: 74.2%
- Description: Simultaneous acquisition of EEG and NIRS during cognitive tasks for an open access dataset
- Paper link: https://www.nature.com/articles/sdata20183.pdf
- Data link: https://doc.ml.tu-berlin.de/simultaneous_EEG_NIRS/
- Device: NIRx NIRScout
- Data type: hbo_hbr 
- is_filtered: False
- LICENSE: CC-BY-4.0

## Task details

- Each trial: 2 s instruction (letter for WG or fixation for BL), 10 s task, 13–15 s rest (fixation)
