# Yi2025

- Subjects: 18
- Epochs: 5735
- Classes: 8 (hand_open, wrist_flexion, wrist_abduction, elbow_pronation, elbow_flexion, shoulder_pronation, shoulder_abduction, shoulder_flexion)
- Task: Fine motor imagery (hand open/close, wrist flexion/extension, wrist abduction/adduction, elbow pronation/supination, elbow flexion/extension, shoulder pronation/supination, shoulder abduction/adduction, shoulder flexion/extension)
- Task type: Motor Imagery (MI, multi-class)
- Classification task:
	- According to the paper, hand vs shoulder yielded the highest accuracy (~62%), but since that would be unbalanced, we use Wrist vs Elbow vs Shoulder.
	- Classification task: Limb[Shoulder|Elbow|Wrist]
	- Cross Acc: 35.8±1.4
	- Within Acc: 39.3±4.5
- Description: Yi2025 Fine Motor Imagery fNIRS dataset
- Paper link: https://www.nature.com/articles/s41597-025-05286-0
- Data link: https://figshare.com/articles/dataset/Data/24123303
- Device: NIRx NIRScout
- Data type: fnirs_cw_amplitude
